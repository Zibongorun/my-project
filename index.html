অনলাইন সংযোগ সেটআপ বাকি

এই সংস্করণ Firebase Realtime Database-এ চলে। Firebase config বসিয়ে Security Rules প্রকাশ করলে account তৈরি করে ব্যবহার শুরু করা যাবে।

  1. নিজের নতুন Firebase project তৈরি করুন।
  2. Authentication-এ Email/Password চালু করুন।
  3. Realtime Database তৈরি করে দেওয়া database.rules.json rules বসান।
  4. HTML-এর firebaseConfig জায়গায় নিজের Web app config বসান।

এখানে অন্য project-এর গোপন key প্রয়োজন নেই। Firebase web config browser-এ থাকে; database নিরাপত্তা Security Rules দিয়ে নিয়ন্ত্রিত হবে।
